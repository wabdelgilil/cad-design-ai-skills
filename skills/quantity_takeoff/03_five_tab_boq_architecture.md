# SKILL-QTO-03: البنية التحتية لملفات الإكسل وقوالب جداول الكميات
## Standardized BOQ Multi-Tab Architecture & Spreadsheet Templates

> **معيار إخراج المخططات وجداول الكميات:**
> "جدول الكميات ليس مجرد صفحة واحدة مكدسة بالأرقام؛ بل هيكل هندسي هرمي متدرج يمكّن الإدارة من رؤية الإجمالي التنفيذي في ثوانٍ، ويمكّن مهندس الموقع من استلام كل دور بمفرده، ويمكّن قسم المشتريات من إصدار أوامر الشراء فوراً."

---

### 1. معمارية التبويبات الخمسة القياسية (The 5-Tab Architecture)

تعتمد المنظومة معمارية قياسية من 5 تبويبات تفاعلية باللغة العربية (RTL):

```
                   ┌─────────────────────────────────────────────────────────┐
                   │             mep_standard_boq_template.xlsx                │
                   └─────────────────────────────────────────────────────────┘
                                                │
         ┌──────────────────┬───────────────────┼───────────────────┬──────────────────┐
         ▼                  ▼                   ▼                   ▼                  ▼
   [التبويب 1]         [التبويب 2]         [التبويب 3]         [التبويب 4]         [التبويب 5]
ملخص الحصر العام     حصر الأدوار التفصيلي   خامات ومستلزمات      شبكات المواسير       قطع الوصل ومستلزمات
 (Executive)       (Floor Breakdown)       التشطيب          (Pipes & Risers)      التركيب والتثبيت
                                         (Specs & Items)                         (Fittings & Hardware)
```

#### تفصيل محتوى ووظيفة كل تبويب:

1. **التبويب 1: ملخص الحصر العام (General Executive Summary):**
   * **الهدف:** موجه لمدير المشروع، الإدارة العليا، والمكتب الفني للمناقصات.
   * **الأعمدة:** [م | التصنيف الرئيسي | توصيف البند ومواصفاته الفنية | الوحدة | الكمية الصافية | نسبة الهالك % | إجمالي كمية التوريد | ملاحظات وتطبيقات الاستخدام].
   * **التقسيم الداخلي:** مقسم إلى 5 فئات رئيسية واضحة (المعدات والخزانات، أجهزة التشطيب، الخلاطات والمحابس، إكسسوارات الحمامات وسيفونات الصرف، شبكات المواسير وقطع الوصل).

2. **التبويب 2: حصر الأدوار التفصيلي (Floor-by-Floor Takeoff):**
   * **الهدف:** موجه لمهندس الموقع والمشرف الميداني لتسليم واستلام الأعمال دوراً بدور.
   * **الأعمدة:** [م | توصيف البند | الوحدة | الأرضي | الأول | الثاني | الثالث | السطح | الملحق | الإجمالي الصافي | إجمالي التوريد (+10%) | ملاحظات وتوزيع الفراغات].
   * **الميزة:** حسابات محابس الزاوية وليات التوصيل موزعة بدقة حسب أجهزة كل دور بشكل مستقل.

3. **التبويب 3: خامات ومستلزمات التشطيب (Finishing Specs & Accessories):**
   * **الهدف:** موجه لقسم المشتريات والتوريدات (Procurement) ومسؤولي الاعتماد المعماري.
   * **المحتوى:** مواصفات الجودة التفصيلية لكل جهاز (الخامة، السماكة، نوع القلب السيراميك، طلاء الكروم، المقاس، والملحقات الحتمية المرفقة معه في صندوق التوريد).

4. **التبويب 4: شبكات المواسير (Piping Networks & Risers Breakdown):**
   * **الهدف:** الحصر المتري الدقيق لجميع مسارات الأنابيب وتتبع الصواعد الرأسية.
   * **الأعمدة القياسية:**
     * م | نوع الشبكة | القطر والخامة
     * الأدوار الأفقية: الأرضي | الأول | الثاني | الثالث | السطح | الملحق
     * **العمود الحاسم: "الصواعد الرأسية المشتركة (م)"** (مستخرج من Riser Diagrams)
     * الإجمالي الصافي: `=SUM(الأدوار + الصواعد)`
     * إجمالي التوريد: `=ROUND(الإجمالي الصافي * 1.1, 0)`
     * ملاحظات الاستخدام ومسارات التمديد والمناور.

5. **التبويب 5: قطع الوصل ومستلزمات التركيب والتثبيت (Fittings & Hardware):**
   * **الهدف:** حصر كافة القطع التكميلية والمستهلكات اللازمة للتركيب الميكانيكي.
   * **المحتوى:**
     * قطع التغذية PPR (أكواع سن نحاس، أكواع 90/45، تيهات، جلب، مساليب، محابس دفن).
     * قطع الصرف PVC (أكواع 4" و 2"، تيهات واي، كعوب صواعد، وصلات تمدد، مصائد روائح).
     * مستلزمات التعليق (قفزان تعليق بالسقف، قفزان صواعد ثقيلة بالمناور، أسياخ تسنين وفليشر).
     * المواد اللاصقة والعازلة (غراء حار ثقيل، برايمر منظف، بكرات تفلون أصلي).

### 2. معايير التصميم البصري وصحة المعادلات (Spreadsheet Engineering Standards)

#### 2.1 حظر الأرقام الصامتة (Zero Hardcoding Rule):
* يُمنع منعاً باتاً كتابة المجاميع الإجمالية أو كميات التوريد كأرقام صامتة ثابتة.
* يجب دائماً كتابة الصيغ الحسابية كمعادلات إكسل حية وديناميكية:
  * عمود الإجمالي الصافي: `=SUM(E5:K5)`
  * عمود التوريد بعد الهالك: `=ROUND(L5*1.1, 0)`
  * خلايا إجمالي الشبكات: `=SUM(E5:E12)`
  * خانة الإجمالي الكلي: `=SUM(K5:K12)`

#### 2.2 لوحة الألوان الهندسية المعتمدة (Professional Color Palette):
* **عنوان اللوحة الرئيسي (Banner):** خلفية كحلي غامق داكن (`#1F4E78`) مع خط أبيض عريض بحجم 14-15pt.
* **رؤوس الأعمدة (Headers):** خلفية زرقاء فولاذية (`#2F5597`) مع خط أبيض عريض 10pt وحدود رفيعة رمادية.
* **رؤوس التصنيفات الرئيسية (Categories):** خلفية زرقاء ثلجية هادئة (`#D9E1F2`) ممتدة على كامل عرض الجدول مع خط غامق 11pt.
* **تمييز كميات التوريد (Procurement Column):** تظليل خفيف خوخي/وردي هادئ (`#F2DCDB` أو `#FCE4D6`) للفت انتباه قسم المشتريات إلى الكمية الواجب شراؤها مباشرة.
* **أسطر التبادل (Zebra Striping):** خلفية بيضاء تتبادل مع رمادي فائق الهدوء (`#F9FAFB`) لتسهيل القراءة الأفقية.

#### 2.3 ضبط التنسيق العربي والطباعة:
* تفعيل اتجاه الورقة من اليمين لليسار إجبارياً:
  ```python
  ws.views.sheetView[0].rightToLeft = True
  ```
* تفعيل التفاف النص التلقائي (`wrap_text=True`) على كافة الخلايا لضمان قراءة الملاحظات والمواصفات بالكامل.
* تنسيق الأرقام القياسي:
  * للأطوال والمسافات: `#,##0.0` (إظهار كسر عشري واحد).
  * للقطع والأطقم والأعداد: `#,##0` (أعداد صحيحة بدون كسور).

### 3. بنية سكربت بايثون المعياري لتوليد جداول الكميات (Python Generator Pattern)

لضمان سهولة تكرار وتوليد هذه الملفات البرمجية لأي مشروع مستقبلي، تم اعتماد هيكل دوال التنسيق الموحدة:

```python
import openpyxl
from openpyxl.styles import Font, Alignment, PatternFill, Border, Side
from openpyxl.utils import get_column_letter

def setup_sheet(ws, title, headers, col_widths, banner_subtitle="مشروع مجمع سكني"):
    ws.views.sheetView[0].rightToLeft = True
    ws.column_dimensions['A'].width = 3
    max_col = len(headers) + 1
    max_col_letter = get_column_letter(max_col)
    
    # Title Banner Row
    ws.merge_cells(f'B2:{max_col_letter}2')
    title_cell = ws['B2']
    title_cell.value = f"{title} | {banner_subtitle}"
    title_cell.font = Font(name="Arial", size=14, bold=True, color="FFFFFF")
    title_cell.fill = PatternFill(start_color="1F4E78", end_color="1F4E78", fill_type="solid")
    title_cell.alignment = Alignment(horizontal="center", vertical="center")
    ws.row_dimensions[2].height = 40
    
    # Headers Row
    start_row = 4
    ws.row_dimensions[start_row].height = 28
    ws.cell(row=start_row, column=2, value="م").alignment = Alignment(horizontal="center", vertical="center")
    ws.cell(row=start_row, column=2).fill = PatternFill(start_color="2F5597", end_color="2F5597", fill_type="solid")
    ws.cell(row=start_row, column=2).font = Font(name="Arial", size=10, bold=True, color="FFFFFF")
    
    for i, h in enumerate(headers):
        c = ws.cell(row=start_row, column=3+i, value=h)
        c.font = Font(name="Arial", size=10, bold=True, color="FFFFFF")
        c.fill = PatternFill(start_color="2F5597", end_color="2F5597", fill_type="solid")
        c.alignment = Alignment(horizontal="center", vertical="center", wrap_text=True)
        
    for col_idx, width in enumerate([5] + col_widths, start=2):
        ws.column_dimensions[get_column_letter(col_idx)].width = width
    return start_row + 1
```
