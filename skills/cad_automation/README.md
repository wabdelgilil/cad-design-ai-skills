# حزمة مهارات أتمتة الكاد بالذكاء الاصطناعي (AI CAD Automation Skills Suite)

## المبادئ الذهبية للأتمتة (Golden Rules)
1. **السرعة والصلابة أولاً:** لا نوافذ رسومية، لا مربعات حوار، لا انتظار لمدخلات المستخدم أثناء التشغيل الخلفي (`FILEDIA=0`, `CMDDIA=0`).
2. **سلامة المخططات:** الفتح دائماً بوضع القراءة فقط (`/readonly`) عند الحصر والفحص لحماية مخططات العملاء والمشاريع الأصلية.
3. **الدقة المكانية بالمعرفات:** تتبع العناصر والمخارج بمقابض الكيانات (`Handles`) وليس بالإحداثيات المجردة.
